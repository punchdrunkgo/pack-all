개발자·외주 없이 3주 안에 Firebase 로그인, 실시간 동기화, PDF 내보내기, 리스트 공유를 갖춘 여행 앱과 일본·베트남·발리·괌·유럽 키워드를 타깃한 SEO 최적화 블로그 11편을 완성했습니다. GA4 커스텀 이벤트 15종을 직접 설계해 실사용 데이터를 수집 중입니다.
Role Split — AI가 한 것과 내가 한 것

👤 내가 담당

  • 어떤 기능이 필요한지 결정
  • 어떤 키워드를 타깃할지 결정
  • UX 흐름과 사용자 경험 판단
  • 결과물 품질 검수 및 수정 지시
  • 전략 → 실행 파이프라인 설계

🤖 AI가 담당

  • 코드 작성 (HTML/CSS/JS 2,500줄+)
  • 블로그 글 초안 작성
  • Unsplash 사진 검색 및 후보 제시
  • SEO 태그·JSON-LD 구조 생성
  • 반복 수정 실행
AI 리터러시가 드러난 순간들
1
기능 추가가 아닌 구조 재설계를 지시
"내 물품 가져오기" 버튼이 한 번 쓰면 잠기는 구조였습니다. 단순히 잠금을 해제하는 게 아니라 사용자가 원하는 항목만 골라서 반복 가져올 수 있는 체크박스 모달로 전체 UX를 다시 설계하도록 지시했습니다.
"한 번 쓰면 잠기는 구조인데, 선택적으로 반복해서 쓸 수 있게 개선하자 — 중복 방지도 포함해서"
2
AI 결과물에 검증 기준을 직접 세움
블로그 이미지를 AI가 제안했을 때, 초기 몇 장이 실제 해당 지역 사진이 아님을 발견했습니다. 이후 "Unsplash 사진 개별 페이지에서 지역 메타데이터가 확인된 사진만 사용"이라는 명확한 기준을 세우고 모든 사진을 원본 URL에서 직접 검증하도록 프로세스를 바꿨습니다.
3
오류를 스스로 감지하고 수정 방법을 지시
AI가 HTML 파일을 생성하다 중간에 잘려 페이지가 깨지는 상황이 발생했습니다. 어느 줄에서 끊겼는지 직접 확인한 뒤, 이어쓰는 방식으로 정확한 수정을 지시해 해결했습니다.
4
전략 판단 → 실행 파이프라인 전체를 연결
"7월에 트래픽이 몰릴 키워드"를 먼저 분석한 뒤, 발리·괌·유럽 3편을 동시에 지시했습니다. 검색 의도 분석 → 글 작성 → 사진 검증 → SEO 설정 → 사이트맵 업데이트 → 배포까지 하나의 흐름으로 이어지는 파이프라인을 혼자 돌렸습니다.
