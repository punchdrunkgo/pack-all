# Packo 네이버 블로그 운영 전략

## 계정 기본 설정

| 항목 | 내용 |
|------|------|
| 블로그명 | Packo — 여행 준비물 전문 블로그 |
| 별명(닉네임) | Packo |
| 프로필 소개 | 나라별·시기별 여행 준비물을 한 번에 정리해드립니다. 짐 걱정 없는 여행을 위해 ✈️ packo-travel.vercel.app |
| 배경/프로필 이미지 | packo 로고 또는 여행 가방 이미지 |

## 카테고리 구성

```
📁 일본 여행
  └ 본토 (도쿄·오사카 등)
  └ 오키나와·섬

📁 베트남 여행
  └ 다낭
  └ 하노이·호치민

📁 동남아 여행
  └ 태국
  └ 기타

📁 여행 짐싸기 꿀팁

📁 여행 필수 앱·도구
```

## 네이버 블로그 vs 웹 블로그 차이점

| 항목 | 웹 블로그 | 네이버 블로그 |
|------|---------|-------------|
| 문체 | 정보 전달형 | 친근한 말투 (~해요, ~드려요) |
| 이미지 | 글당 2~3장 | **글당 10~20장 권장** |
| 길이 | 1,500~3,000자 | **2,000~4,000자** |
| 제목 | 키워드 + 연도 | 키워드 + 감성 문구 |
| 태그 | 없음 | **20~30개 필수** |
| 내용 | 동일 OK | 웹과 살짝 다르게 (중복 방지) |

## 포스팅 일정

- **빈도**: 주 2~3회
- **최적 발행 시간**: 오전 7~9시 / 오후 8~10시
- **순서**: 웹 블로그 글 → 1~2일 후 네이버 재가공 발행

## 제목 공식

```
[핵심 키워드] + [연도 or 숫자] + [감성/클릭 유도 문구]
```

예시:
- ✅ "다낭 5월 날씨 2026 | 건기라서 좋은 줄 알았는데 이것 몰랐어요"
- ✅ "다낭 마사지 종류 8가지 가격 비교 | 아로마 vs 핫스톤 뭐가 나을까"
- ❌ "다낭 5월 6월 날씨 및 필수 준비물 정리" (너무 딱딱, 웹 제목과 동일)

## 태그 전략

- 상위 태그(조회수 높음): #다낭여행 #베트남여행 #해외여행준비물
- 중간 태그(경쟁 적음): #다낭5월날씨 #다낭마사지추천 #다낭여행준비물
- 롱테일 태그: #다낭썬번마사지 #다낭임산부마사지 #다낭미케비치준비물

→ **세 가지 유형을 섞어서 20~30개** 사용

## 글 마무리 공식 (매 글 동일하게 사용)

```
---
📌 준비물 체크리스트가 필요하다면?
Packo 앱에서 나라별 준비물을 체크하면서 챙길 수 있어요.
👉 packo-travel.vercel.app
---
```
